# JavaScript Callback-Based Candidate Screening System

Simple, small examples showing how to work with candidate data in JavaScript.

Files:
- `one_filtercan.js` — examples of filtering candidates (availability, scores, skills, graduation year).
- `two_transformcandiate.js` — mapping/transformation examples (names, total scores, skill counts, formatted strings).
- `three_CalCandidate.js` — calculating candidate scores with different weighting and bonuses.
- `four_shortCandidate.js` — shortlisting candidates based on availability, skills, and final score.
- `five_sortCandi.js` — sorting candidates by test score, interview score, final score, name.
